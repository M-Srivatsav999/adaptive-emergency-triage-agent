Before you start

  • This tool gives general guidance only. It is not a doctor and does not diagnose.
  • If someone is very ill, get emergency help now - do not wait for this tool.
  • What you type stays on this clinic computer. It may be saved for a limited time to check the tool's safety, and you can ask for it to be deleted.
  • Please do not type names, phone numbers or addresses.
